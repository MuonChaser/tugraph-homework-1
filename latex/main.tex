\section{实验目标与整体设计}

本实验完成 TuGraph 平台部署、图模型建立、CSV 数据导入、增删改查及自定义聚合查询，以疾病、症状、科室和药品为实体：节点保存实体属性，边表示实体关联，Cypher 用于模式匹配与统计。


整体流程为：UTF-8 CSV → JSON 图模型和字段映射 → lgraph\_import 原生导入 → TuGraph 存储引擎 → Browser 查询交互。节点用 name 作为主键，关系文件按主键连接节点。原始 CSV 与数据库目录分别保存，便于复现和备份。


由于本地设备性能充足，本实验采用 Docker 在本地部署 TuGraph。运行环境为 Windows Docker Desktop 的 Linux 容器，数据库来自官方发布的 4.5.1 RPM 包。最终容器使用 Debian 13 基础环境，宿主机 HTTP 17070、Bolt 17687、RPC 19090 映射至容器对应端口，映射地址限定为 127.0.0.1。

\section{安装、部署与启动}

从 TuGraph 官方 GitHub Release 下载 4.5.1 RPM 安装包。在容器中安装 rpm2cpio、cpio、libgomp1、libgfortran5 后解包二进制和 Browser 资源，服务成功启动。Dockerfile 固定基础镜像 digest，入口替换为 lgraph\_server。


在项目目录启动 Docker Desktop 后，执行 setup.ps1，构建镜像、导入 CSV 数据并启动服务。启动的核心命令为：


\begin{Code}
docker run -d --name tugraph-assignment --restart unless-stopped `
  -p 127.0.0.1:17070:7070 -p 127.0.0.1:17687:7687 `
  -p 127.0.0.1:19090:9090 `
  --mount "type=bind,source=${PWD},target=/workspace" `
  tugraph-assignment-clean:4.5.1

docker ps --filter name=tugraph-assignment
docker logs --tail 30 tugraph-assignment
\end{Code}

服务读取 \path{config/lgraph.json}，数据库位于 \path{/workspace/runtime/db}。浏览器访问 \path{http://127.0.0.1:17070}，填写 Bolt 地址 127.0.0.1:17687，使用账号 admin、默认密码 73@TuGraph 登录，进入 medical\_demo 图项目。


启动日志显示 TuGraph Graph Database v4.5.1，包含以下成功信息；完整原始输出保存在 \path{evidence/startup.log}：


\begin{Code}
Listening for RPC on port 9090
Listening for REST on port 7070
bolt server run
Server started.
\end{Code}

\subsection{CSV 导入与数量核对}

准备四份节点文件 diseases.csv、symptoms.csv、departments.csv、drugs.csv，以及三份关系文件 disease\_symptom.csv、disease\_department.csv、disease\_drug.csv。文件使用 UTF-8 编码，首行为表头；import.json 的 header 设为 1。


import.json 中 schema 定义标签、属性、主键和边约束，files 定义文件路径与列映射。例如疾病症状边的映射如下：


\begin{Code}
{
  "path": "/workspace/data/disease_symptom.csv",
  "header": 1, "format": "CSV", "label": "HAS_SYMPTOM",
  "SRC_ID": "Disease", "DST_ID": "Symptom",
  "columns": ["SRC_ID", "DST_ID"]
}
\end{Code}

在空数据库目录执行原生离线导入：


\begin{Code}
lgraph_import --config_file /workspace/data/import.json \
  --dir /workspace/runtime/db --graph medical_demo
\end{Code}

导入日志显示四个 vertex label 和三个 edge label 均创建成功，结束信息为 Import finished in 0.338341 seconds。启动服务后，再通过 Cypher 分类型核对导入数量。

\section{自定义聚合查询}

本实验统计每种疾病关联的不同症状数量。MATCH 匹配疾病到症状的路径，按疾病分组，用 count(DISTINCT s) 去重计数，再按数量降序排序。


\begin{Code}
MATCH (d:Disease)-[:HAS_SYMPTOM]->(s:Symptom)
RETURN d.name AS disease, count(DISTINCT s) AS symptom_count
ORDER BY symptom_count DESC;
\end{Code}
